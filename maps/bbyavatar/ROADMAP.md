# BBYAVATAR Growth Roadmap

Target: Universe 10744157359 / Place 85866320744490

## Product loop
DISCOVER -> TRY/STYLE -> SAVE -> SHOP -> SHARE -> RETURN

## Phase A — Core catalog
- Marketplace search and category discovery
- Interactive physical look pods
- Avatar Studio save/create outfit flow
- Favorites and purchase prompts
- Mobile-first catalog UX

## Phase B — Retention
- Daily featured rotation architecture
- New Drops / Trending / Creator Picks discovery lanes
- Saved wardrobe entry points
- Recently viewed / recommendation-ready state
- Photo Studio and social dwell spaces

## Phase C — Community
- Creator Spotlight collections
- Community looks submission architecture with moderation gates
- Likes/votes only after abuse-resistant server validation
- Outfit codes/shareable collection identifiers where platform policy permits

## Phase D — Digital asset
- Curated BBYAVATAR-owned collections
- Creator partnership slots
- Seasonal drops and branded virtual events
- Analytics-ready funnel: browse -> view -> save -> purchase
- Conversion/retention dashboards when telemetry backend is approved

## Hard rules
- Never fake catalog ownership, prices, sales, or creator attribution.
- Never enable arbitrary client-controlled purchases.
- Marketplace/purchase actions must remain Roblox-native and policy compliant.
- Mobile readability and performance are release gates.
- Publish only to the locked BBYAVATAR target.
- Persist deploy receipt after every production publish.
