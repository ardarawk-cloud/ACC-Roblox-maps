# BBYA SOCIAL HUB — Production Starter

Source package for the BBYA Social Hub Roblox experience.

## Locked identity
- BBYA Queen UserId: `4271188557`
- Sensitive permissions are server-authoritative and UserId-based.

## Included
- Role/permission system
- Remote rate limiting
- Music controller
- Lighting presets
- VIP/Queen access
- Queen throne reactive effects
- Support purchase scaffold
- Dance client
- Studio bootstrap hierarchy

## Install into Roblox Studio
Run `ServerScriptService/StudioBootstrap.server.lua` once, then place each script/module under its matching Roblox service. Replace placeholder audio/product IDs in Config before publishing.

This package lives alongside the current `maps/a-club` build so existing active BBYA files are not overwritten blindly.
